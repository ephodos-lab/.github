# Brand assets

| File | Use |
| --- | --- |
| `avatar.svg`, `avatar-1024.png`, `avatar-512.png` | Square avatar on the ink ground |
| `mark-on-dark.svg` | The mark alone, for dark backgrounds |
| `mark-on-light.svg` | The mark alone, for light backgrounds |
| `banner.png` | Wide header with the wordmark |
| `banner.svg` | Source of the banner; its text uses the typefaces listed below |

The mark is a titling capital E in a double ring. The faint figure behind the banner is a circle and a square of equal area. The letter in the SVG marks is drawn as an outline, so they render the same everywhere.

## Colours

| Name | Hex | Use |
| --- | --- | --- |
| Ink | `#0B1220` | Background |
| Ivory | `#EAE3D2` | Letters and text |
| Gold | `#C9A45C` | Rings and rules on dark backgrounds |
| Deep gold | `#A8843E` | Rings and rules on light backgrounds |

## Typefaces

- Wordmark and monogram: Perpetua Titling MT
- Tagline: Garamond Italic
- Greek: Palatino Linotype
