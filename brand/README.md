# Brand assets

The mark is a dotted vortex: arms of dots spiral into an off-centre throat, a picture of many lines of work converging on one problem. The wordmark sets EPHODOS LAB in Cormorant Garamond with the first O drawn as a crescent.

Every file here is generated by [`src/build.py`](src/build.py); the vortex is parametric, not traced.

| File | Use |
| --- | --- |
| `mark.svg`, `mark-on-dark.svg` | The vortex alone, transparent ground |
| `wordmark.svg`, `wordmark-on-dark.svg` | EPHODOS LAB alone |
| `lockup.svg`, `lockup-on-dark.svg`, `lockup.png` | Vortex above the wordmark and tagline (square) |
| `avatar.svg`, `avatar-1024.png`, `avatar-512.png` | Square avatar on white, with a heavier cut of the vortex for small sizes |
| `avatar-on-dark.svg`, `avatar-on-dark-1024.png` | The same on the ink ground |
| `banner.svg`, `banner.png` | Wide header: vortex, wordmark and tagline |

## Colours

| Name | Hex | Use |
| --- | --- | --- |

| Paper | `#FFFFFF` | Light ground |
| Ivory | `#EAE3D2` | The mark and text on the dark ground |

## Typefaces

- Wordmark: [Cormorant Garamond](https://github.com/CatharsisFonts/Cormorant) (weight 530 for EPHODOS, 300 for LAB)
- Tagline: [Jost](https://github.com/indestructible-type/Jost) Light, tracked wide

Both are under the SIL Open Font License 1.1. The SVG files contain the letters as outlines, so they need no fonts to display.

## Regenerating

```bash
pip install numpy fonttools
python src/build.py --fonts FONTS_DIR --out .
```

`FONTS_DIR` must hold `CormorantGaramond[wght].ttf` and `Jost[wght].ttf` from [google/fonts](https://github.com/google/fonts) (`ofl/cormorantgaramond`, `ofl/jost`). The PNG files are renders of the SVGs.
