# Brand assets

| File | Use |
| --- | --- |
| `avatar.svg`, `avatar-1024.png`, `avatar-512.png` | Square avatar on the dark ground |
| `mark.svg` | The mark alone, on a transparent ground |
| `banner.svg`, `banner.png` | Wide header with the wordmark |

The mark shows the idea behind Archimedes' *Ephodos* (*The Method*): a circle and a square of equal area, weighed against each other on a lever.

## Colours

| Name | Hex |
| --- | --- |
| Ink | `#102033` |
| Parchment | `#F1E7D3` |
| Terracotta | `#E0703F` |

The wordmark is set in Palatino (Palatino Linotype or Book Antiqua).

## Using the name and logo

You may use the Ephodos Lab name and logo to refer to the organization and its projects. Please do not alter the logo, and do not use either in a way that suggests we endorse a product, service or result that we do not.
